# Audit coverage inventory

Baseline product HEAD: 64b766078f91ed7069fb682d09e65a549bbe0211.
This document is an inventory generated without running the audit. Automated
clauses are deliberately unverified here. See RUNBOOK.md for self-contained run
instructions and scripts/audit/registry.mjs for editable clause/check bindings.

Design decision: B (requirement registry) prevents an unrelated broad-ID pass
from satisfying manual or missing evidence. A (probe tags plus prose) leaves
acceptance semantics implicit. The pure aggregator owns this distinction.

Runtime evidence is invalidated if specifications, product source, HEAD, the audit
script or its helpers drift during a run. The generated requirement reports name
the invalidation reason; this no-execution inventory never grants a runtime pass.

Data shape: requirement {id, clause, source, scope, mode, checkNames,
manualInstructions, acceptedException}; runtime check {name, ids, status,
evidence/error}. All checkNames are exact runtime names. Optional and excluded
items never inflate mandatory counts. Accepted exceptions never become passes.

Public coverage is a named subset (normal/failure/recovery/mobile theme),
independent from local checks after the owned preview stops. It is not the
complete public matrix. Any loopback attempt is rejected and reported.
